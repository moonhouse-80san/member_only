# 회원 전용 게시글 1.3.0

확장변수(`member_only`)가 체크된 게시글을 로그인 회원에게만 보여주는 라이믹스 모듈입니다.

| 항목 | 내용 |
| --- | --- |
| 종류 | 라이믹스 모듈 (Rhymix 2.x) |
| 버전 | 1.3.0 (2026-11-27) |
| 설치 경로 | `/modules/member_only` |
| 자료실 | https://moonhouse.co.kr/xemy/621023 |
| 저작자 | 80san (문하우스) |
| 라이선스 | GPL v2 |

## 주요 기능

- 게시판 사용자정의(확장변수)에 `member_only`(단일선택 Y/N)를 추가하고, 체크된 글만 로그인 회원에게 본문을 공개합니다.
- 목록에서의 처리 방식을 고를 수 있습니다. — 가림(hide) / 마스킹(mask) / 그대로 표시(show)
- 대상 게시판과 대상 회원그룹을 지정해 필요한 곳에만 적용합니다.
- 열람 레벨 확장변수: 글에 적어 둔 레벨보다 방문자 레벨이 낮으면 본문을 볼 수 없습니다. (기본 ID `read_level_rh`)
- **비밀번호 잠금 (1.3.0 추가)** — 로그인하지 않은 방문자도 관리자가 정한 비밀번호를 입력하면 글을 열람할 수 있습니다.
- **검색봇 허용 (1.3.0 추가)** — 구글(Googlebot)·네이버(Yeti)는 역방향 DNS 조회 후 정방향으로 다시 조회해 IP가 일치할 때만 통과시킵니다. User-Agent만 흉내 낸 접근은 걸러집니다.
- 관리자 설정 화면(모듈 설정)에서 위 항목을 모두 관리합니다.

## 요구 사항

- 라이믹스 2.x
- PHP 8.0 이상 권장

## 설치

1. 내려받은 폴더를 `/modules/member_only`에 업로드합니다.
2. 관리자 > 모듈 > 모듈 설치에서 **회원 전용 게시글**을 설치합니다.
3. 관리자 > 회원 전용 게시글 설정에서 아래 항목을 지정합니다.
4. 적용할 게시판의 사용자정의에 확장변수를 추가합니다.
   - `member_only` : 단일선택 (Y / N)
   - (레벨 제한을 쓸 때) `read_level_rh` : 숫자 입력 — 필요한 레벨 값
5. 관리자 > 캐시파일 재생성.

## 설정 항목

| 항목 | 설명 |
| --- | --- |
| 확장변수 ID | 전용글 판단에 쓸 확장변수 ID (기본 `member_only`) |
| 목록 처리 | 가림 / 마스킹 / 표시 |
| 열람 레벨 확장변수 | 레벨 제한에 쓸 확장변수 ID (기본 `read_level_rh`) |
| 비밀번호 사용 | 로그인 없이 비밀번호로 열람 허용 (Y/N)와 비밀번호 |
| 검색봇 허용 | Googlebot·Yeti는 본문을 볼 수 있게 허용 (Y/N) |
| 대상 게시판 | 적용할 게시판 선택 |
| 대상 회원그룹 | 적용할 회원그룹 선택 |

## 주의 사항

- 최근글 위젯에서도 제목을 가리려면 자료실 게시물에 함께 올려 둔 `content.zip`(content 위젯 패치)을 적용해야 합니다. **content 위젯을 업데이트하면 패치가 초기화되므로** 업데이트 후 다시 적용해야 합니다.
- 검색봇 허용을 켜 두어도 서버가 역방향 DNS 조회를 하지 못하는 환경이라면 검색봇도 차단될 수 있습니다.
- 비밀번호는 해시로 저장됩니다. 비밀번호를 잊었다면 설정에서 새로 지정하면 됩니다.
- 모듈을 삭제해도 게시글에 입력한 확장변수 값은 남습니다. 다시 설치하면 그대로 동작합니다.
